# Bot File Archive

This directory is the repository-backed home for one bot in Killian's Organised Archives.

Use the shelves consistently:
- `character/` — master docs, canon locks, voice/personality notes and source references
- `worldbooks/` — worldbooks, lorebooks, routing files and continuity patches
- `platforms/` — Tipsy, CraveU, CrushOn and other platform-specific packages
- `visuals/` — portraits, banners, cards and other bot artwork
- `promo/` — promo copy, launch posts, captions and campaign assets
- `exports/` — final backups, release bundles and portable copies

Legacy files already present in a bot folder may stay at the root. Do not destructively reorganise an established package just to match the shelves.
